# Rights And Reuse

This repository does not grant a blanket license for images, thumbnails, pet spritesheets, generated frames, or derivative packages.

Before public, commercial, redistributed, or generated derivative use, check:

- `metadata/characters.csv`
- `metadata/pets.csv`
- `RIGHTS.md`
- `LICENSE`

## Current status

The current character rows use:

- `rights`: `unknown`
- `usage_scope`: `internal-review`

That means the assets are visible as a public catalog, but they should not be treated as commercially reusable or redistributable until the metadata is updated.

## Source files and previews

Large source files and reference bundles belong in Git LFS-managed paths:

```text
assets/originals/
assets/references/
```

GitHub-renderable preview files stay as normal Git blobs:

```text
assets/exports/
assets/thumbnails/
assets/pets/
```
